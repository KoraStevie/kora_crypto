# Items

The resource defines no items. It requires an item named `cryptostick` to exist in the inventory used through `qb-inventory`. One stick is consumed per attempt, whether the minigame succeeds or fails.

Qbit itself is not an item: it is a `crypto` money account handled by `kora_core` (`addMoney(src, 'crypto', amount, reason)`).
